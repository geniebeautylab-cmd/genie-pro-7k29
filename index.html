1 기본 세팅

먼저 컴퓨터에 세 가지를 준비해요. ①번부터 순서대로 하세요.

① Claude Pro 가입 & Claude Code 열기 (제일 먼저!)

AI(Claude)가 글을 쓰고 일을 다 해요. 먼저 Pro 요금제에 가입하세요. (API 키 필요 없어요)

Claude Pro 구독하러 가기 ↗

가입 후, Claude 앱(또는 claude.ai) 우측 상단의 </> (코드) 아이콘을 클릭하면 Claude Code 창이 열려요. 이 창이 앞으로 모든 작업의 무대예요.

💡 </> 아이콘이 안 보이면 → Claude 데스크톱 앱을 최신으로 업데이트하거나 claude.ai 에 로그인해 보세요.

스킬을 받아오려면 git이 필요해요.

🍎 맥: Claude가 git을 처음 쓸 때 '명령어 도구 설치' 팝업이 자동으로 떠요 → "설치"만 누르면 끝! (안 뜨면 아래 버튼으로)

🪟 윈도우: 자동으로 안 떠요. 아래 Git for Windows를 받아 설치하세요.

git 설치 페이지 ↗

인스타 카드뉴스 이미지를 만들 때 Node.js가 필요해요. LTS 버전으로 설치해두세요.

2 Aside 설치하고 로그인하기

Aside는 AI가 들어 있는 인터넷 브라우저예요. Claude Code가 글을 쓰면, Aside가 화면을 직접 눌러서 블로그·인스타·스레드에 올려요. 크롬 확장은 쓰지 않아요.

Aside 설치하고 Claude 연결하기

아래 사진은 실제 Aside 화면이에요. 빨간 네모만 따라 누르면 돼요.

① Aside 내려받기

  1. 아래 버튼을 눌러 Aside 홈페이지로 가요.
  2. 가운데 검은색 Download 버튼을 눌러요.
  3. 내려받은 파일을 열어 설치하고, Aside를 실행해요.
  4. 처음 켜면 구글 계정으로 로그인해요.
Aside 다운로드 ↗

② 내 Claude 구독 연결하기

  1. 맨 위 메뉴에서 Aside → 설정을 눌러요.
  2. 왼쪽 목록에서 Models를 눌러요.
  3. + Connect를 누르고 Claude를 골라 로그인해요.
  4. 사진처럼 Claude · Subscription이 보이면 연결 끝이에요.

③ 새 채팅에서 두 가지 바꾸기

  1. 왼쪽 위 New Chat을 눌러요.
  2. 입력창 왼쪽 아래를 눌러 Ask first로 바꿔요. (올리기 전에 원장님께 먼저 물어봐요)
  1. 입력창 오른쪽 아래를 눌러 Claude Sonnet을 골라요.
⚠️ “Skip confirmation”이 켜져 있으면 확인 없이 바로 발행돼요. 꼭 “Ask first”로 바꿔 두세요.
메뉴 이름은 업데이트로 조금 바뀔 수 있어요. 안 보이면 Aside 채팅창에 “Claude 구독 연결하는 방법 알려줘”라고 물어보세요.

④ Aside CLI 설치하기 (꼭 해야 해요)

CLI는 Claude Code가 Aside를 부를 때 쓰는 “연결 통로”예요. 이게 없으면 Claude Code는 Aside가 설치된 줄도 몰라요. 글은 써도 올리지 못해요.

  1. 맨 위 메뉴에서 Aside → 설정을 눌러요.
  2. 왼쪽 목록 맨 아래쪽 Developers를 눌러요.
  3. 맨 위 Aside CLI 상자에서 검은색 Install 버튼을 눌러요. (사진처럼 Reinstall로 바뀌면 설치된 거예요)
  4. 바로 아래 Enable Aside MCP server 스위치가 초록색(켜짐)인지 확인해요.
  1. 이제 Claude Code로 돌아와서 아래 문장을 그대로 붙여넣어요.

Claude Code가 “설치되어 있어요”라고 답하면 Aside 설치 끝이에요. “없어요”라고 하면 위 3번 Install 버튼을 다시 누르고, Claude Code를 껐다 켠 뒤 한 번 더 물어보세요.

✅ 여기까지 해야 Aside 설치 완료예요. Aside 앱만 깔고 CLI를 안 깔면, 4번 “이어 주기”에서 Claude Code가 Aside를 못 찾아요.

계정 3개에 한 번씩 로그인하기

  • Aside 브라우저로 네이버, 인스타그램, 스레드에 한 번씩 로그인해요. 네이버는 “로그인 상태 유지”를 체크하세요. (로그인이 안 돼 있으면 AI가 글쓰기 화면에서 멈춰요)
  • 비밀번호는 Aside 비밀번호 관리자에 저장하세요. AI는 비밀번호를 보지 못하고, 자동입력으로만 로그인해요.
  • 채팅창에 비밀번호를 직접 적지 마세요.
💡 알아두세요
· 로그인은 꼭 Aside 안에서 해요. 크롬에 로그인돼 있어도 Aside는 그걸 못 써요.
· 글을 올리는 동안 컴퓨터와 Aside는 켜 두세요.

각 스킬은 특정 요청에 자동으로 발동합니다. 블로그 자동화엔 블로그·마케팅 핵심 3종이 특히 강력해요.

⭐ 블로그·마케팅 핵심

naver-blog-writing 핵심

네이버 블로그 전용 프레임워크. PREP 구조, 업종별 반박제거, CTA 3공식, 상위노출 8원칙, 가독성 10원칙. “블로그 글 써줘/상위노출 되게” 하면 자동 발동.

marketing-science-writing 핵심

행동경제학·소비자 심리 기반 설득 카피. 카드뉴스·인스타/스레드 캡션·유튜브 스크립트·세일즈 카피·후크·CTA. “더 설득력 있게” 하면 자동 발동.

homepage-builder-kr 핵심

한국어 홈페이지/랜딩/쇼핑몰을 인터뷰→Next.js→Supabase→토스페이먼츠→Vercel 배포까지 한 흐름으로 제작.

🛠 기획·자동화 보조

feature-planner 보조

기능/프로젝트를 단계별 계획으로 쪼개고 품질 게이트를 세우는 기획 스킬.

team 보조

여러 AI 에이전트를 팀으로 묶어 병렬 작업. “팀 만들어/동시에 진행” 시 발동.

find-hooks 보조

커뮤니티에서 Claude Code 훅·명령·플러그인·MCP를 찾아 설치. “훅 추천해줘” 시 발동.

skillsmp-search 보조

SkillsMP 마켓플레이스에서 필요한 AI 스킬을 키워드·의미 검색으로 발굴.

agent-reach 보조

AI에게 트위터·레딧·유튜브·깃허브 등 인터넷/소셜 접근을 하나로 열어주는 CLI 설치·설정.

merge-worktree 보조

깃 워크트리 브랜치를 메인으로 스쿼시 병합하며 커밋 메시지를 자동 정리.

orca CLI 연동 스킬(외부 도구).

문제해결 FAQ

스킬이 발동 안 해요 → “이 스킬들을 클론해서 세팅해줘”로 세팅됐는지 확인. 세팅 후엔 ~/.claude/skills/ 안에 폴더가 있어야 합니다.

AI가 글을 안 써요 → claude 구독 로그인 확인. API 키 넣지 마세요.

토큰(claude setup-token)을 꼭 발급해야 하나요? → 아니요, 안 하셔도 돼요! Claude Code에 로그인만 되어 있으면 자동으로 인증돼요. 터미널에 claude 입력 → 한 번 로그인하면 끝. .env에 토큰 넣는 부분은 건너뛰세요. (토큰은 서버 등 특수한 경우에만 쓰는 예비용이에요.)

Claude Code가 Aside를 못 찾아요 → 먼저 2번 ④ Aside CLI가 설치됐는지(설정 → Developers에 “Reinstall”이 보이는지) 확인하고, 4번 “Claude Code와 Aside 이어 주기” 문장을 다시 붙여넣으세요. Aside 브라우저가 켜져 있는지도 확인해요.

AI가 로그인에서 멈춰요 → Aside 브라우저에서 그 사이트에 직접 한 번 로그인하세요. 네이버는 “로그인 상태 유지”를 체크해요.

글자 크기나 줄바꿈이 이상해요 → 진행 중에 바로 “본문 전체 15pt로 맞춰줘”, “한 문장 한 줄로 다시 나눠줘”라고 말하면 고쳐줘요.

카드뉴스 이미지를 못 만들어요 → 1번의 Node.js가 설치됐는지 확인하세요. Claude Code에 “node -v 확인해줘”라고 하면 돼요.
