Aside 브라우저로 하기

Claude Code로 프로그램 만들기

🔰 쉬운 버전: Aside로 코딩 없이

Aside는 AI가 들어 있는 인터넷 브라우저예요. 크롬처럼 쓰면서 “블로그 글 써서 올려줘”라고 말하면, AI가 화면을 보고 직접 글을 쓰고 올려요. 이미 쓰고 있는 Claude 구독을 그대로 연결해서 써요.

1단계. Aside 설치하고 Claude 연결하기

  1. 아래 버튼을 눌러 Aside를 받아 설치해요. (맥·윈도우 모두 있어요)
  2. Aside를 열고 설정에서 AI를 Claude로 고른 뒤, 내 Claude Pro 계정으로 연결해요.
Aside 다운로드 ↗
메뉴 이름은 업데이트로 조금 바뀔 수 있어요. 안 보이면 Aside 채팅창에 “Claude 구독 연결하는 방법 알려줘”라고 물어보세요.

2단계. 계정 3개에 한 번씩 로그인하기

  • Aside 브라우저로 네이버, 인스타그램, 스레드에 한 번씩 로그인해요.
  • 비밀번호는 Aside 비밀번호 관리자에 저장하세요. AI는 비밀번호를 보지 못하고, 자동입력으로만 로그인해요.
  • 채팅창에 비밀번호를 직접 적지 마세요.

3단계. 아래 프롬프트 붙여넣기

아래 상자를 눌러 복사하고, Aside 채팅창에 붙여넣으세요. [내 정보] 칸만 원장님 것으로 채우면 돼요.

4단계. 첫 글은 비공개로 테스트

  • 처음엔 공개범위를 비공개로 두고 한 번 끝까지 해보세요.
  • 글자 크기, 줄바꿈, 사진이 괜찮은지 직접 확인해요.
  • 괜찮으면 [내 정보]의 공개범위를 전체공개로 바꿔요.

5단계. 매일 반복하기

잘 되면 이 작업을 “매일 오전 9시에 반복해줘”라고 부탁해서 반복 작업으로 저장하세요. 다음부터는 AI가 글을 다 준비해 두고, 원장님은 확인 버튼만 누르면 돼요.

💡 알아두세요
· Aside는 글 올리기처럼 중요한 일은 원장님 확인을 받고 진행해요. 공개범위 사고를 막아주는 안전장치예요.
· 컴퓨터가 켜져 있어야 작업해요.
· 원장 스킬 팩은 Claude Code용이에요. Aside에서는 위 프롬프트에 핵심 규칙을 담아 두었어요.

★ 원장 스킬 팩 (Claude에게 맡기기)

유료판의 핵심 — 네이버 블로그 글쓰기·마케팅 카피·랜딩페이지·기획·팀 자동화까지, 원장이 실제로 쓰는 스킬 10종이에요.

Claude Code를 열고, 아래 문장을 그대로 복사해서 붙여넣으세요. Claude가 스킬을 받아 ~/.claude/skills/ 에 세팅까지 알아서 해줘요.

🔒 비밀번호 입력 후 여기에 표시됩니다
📌 세팅이 끝나면, 앞으로 “블로그 글 써줘” 같은 요청에 이 스킬들이 자동으로 적용돼요 (예: naver-blog-writing 스킬 발동). 따로 켤 필요 없어요.

마스터 프롬프트 (개선판)

코드를 내려받지 않습니다. 아래 프롬프트를 Claude Code 계획모드(창에서 Shift+Tab)에 붙여넣으면 AI가 자동화 프로그램 전체를 만들어 줍니다. 이번에 겪은 버그(글자크기·₩n·사진중복·공개범위 사고)를 미리 막는 품질 스펙 포함.

AI가 계획을 보여주면 승인 → 코드 생성·실행. 중간에 블로그 ID·키워드·발행 시간·타깃·CTA를 물어보면 원장님 것으로 답하세요. 스킬 팩을 먼저 세팅해뒀다면, 글 품질이 훨씬 좋아집니다.

네이버 로그인 & 첫 발행

대시보드는 http://localhost:3000 에 뜹니다.

  • 네이버 로그인 버튼 → 창에서 직접 로그인(세션 저장돼 다음부턴 자동)
  • 설정에서 블로그 ID·키워드·발행 시간·하루 1건 지정
  • 글감찾기 → 초안확인 → 발행. 첫 발행은 꼭 비공개로 테스트
✅ 발행 전 공개범위 검증이 켜져 있어, 비공개가 실제로 선택 안 되면 발행을 멈춥니다.

(선택) 이미지 고도화: Pexels 무료 키를 .env에 넣으면 사진 품질이 올라갑니다.

포함된 스킬 10종

각 스킬은 특정 요청에 자동으로 발동합니다. 블로그 자동화엔 블로그·마케팅 핵심 3종이 특히 강력해요.

⭐ 블로그·마케팅 핵심

naver-blog-writing 핵심

네이버 블로그 전용 프레임워크. PREP 구조, 업종별 반박제거, CTA 3공식, 상위노출 8원칙, 가독성 10원칙. “블로그 글 써줘/상위노출 되게” 하면 자동 발동.

marketing-science-writing 핵심

행동경제학·소비자 심리 기반 설득 카피. 카드뉴스·인스타/스레드 캡션·유튜브 스크립트·세일즈 카피·후크·CTA. “더 설득력 있게” 하면 자동 발동.

homepage-builder-kr 핵심

한국어 홈페이지/랜딩/쇼핑몰을 인터뷰→Next.js→Supabase→토스페이먼츠→Vercel 배포까지 한 흐름으로 제작.

🛠 기획·자동화 보조

feature-planner 보조

기능/프로젝트를 단계별 계획으로 쪼개고 품질 게이트를 세우는 기획 스킬.

team 보조

여러 AI 에이전트를 팀으로 묶어 병렬 작업. “팀 만들어/동시에 진행” 시 발동.

find-hooks 보조

커뮤니티에서 Claude Code 훅·명령·플러그인·MCP를 찾아 설치. “훅 추천해줘” 시 발동.

skillsmp-search 보조

SkillsMP 마켓플레이스에서 필요한 AI 스킬을 키워드·의미 검색으로 발굴.

agent-reach 보조

AI에게 트위터·레딧·유튜브·깃허브 등 인터넷/소셜 접근을 하나로 열어주는 CLI 설치·설정.

merge-worktree 보조

깃 워크트리 브랜치를 메인으로 스쿼시 병합하며 커밋 메시지를 자동 정리.

orca-cli 보조

orca CLI 연동 스킬(외부 도구).

스킬은 원장님이 직접 만들거나 설치해 쓰던 것들입니다. 일부(agent-reach·skillsmp-search·orca-cli)는 외부 오픈소스 도구를 설치/연동하는 스킬이라, 실제 사용 시 각 도구의 안내를 따르세요.

문제해결 FAQ

스킬이 발동 안 해요 → “이 스킬들을 클론해서 세팅해줘”로 세팅됐는지 확인. 세팅 후엔 ~/.claude/skills/ 안에 폴더가 있어야 합니다.

AI가 글을 안 써요 → claude 구독 로그인 확인. API 키 넣지 마세요.

토큰(claude setup-token)을 꼭 발급해야 하나요? → 아니요, 안 하셔도 돼요! Claude Code에 로그인만 되어 있으면 자동으로 인증돼요. 터미널에 claude 입력 → 한 번 로그인하면 끝. .env에 토큰 넣는 부분은 건너뛰세요. (토큰은 서버 등 특수한 경우에만 쓰는 예비용이에요.)

네이버 창만 뜨고 멈춰요 → “playwright chromium 설치해줘” 요청.

비공개인데 공개로 나갔어요 → “공개범위 selector를 다시 확인해서 selectors.json 고쳐줘” 요청.

[Aside] 쉬운 버전이랑 고급 버전, 같이 써도 되나요? → 네. 하지만 같은 날 같은 블로그에 둘 다 발행하면 글이 겹칠 수 있어요. 하나만 골라 쓰세요.

[Aside] AI가 로그인에서 멈춰요 → Aside 비밀번호 관리자에 그 사이트 계정이 저장돼 있는지 확인하세요. 없으면 직접 한 번 로그인하고 저장해요.

[Aside] 글자 크기나 줄바꿈이 이상해요 → 진행 중에 바로 “본문 전체 15pt로 맞춰줘”, “한 문장 한 줄로 다시 나눠줘”라고 말하면 고쳐줘요.
